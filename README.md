# pirate-can-focus-too

Une app Android de concentration où un capitaine pirate en pixel art t'aide à garder le cap.
Termine une traversée pour gagner des doublons, abandonne et le navire coule.

## Lancer le projet

1. Ouvrir le dossier dans Android Studio.
2. Laisser Android Studio synchroniser Gradle (il télécharge Gradle 8.11.1 et génère le wrapper si besoin).
3. Lancer la configuration `app` sur un émulateur ou un téléphone.

Tests unitaires : `./gradlew test` (logique du minuteur dans `FocusTimerTest`).
